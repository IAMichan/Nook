First run

Up and running in a minute.

Download and openDrag Nook to Applications. Because the beta is not notarized yet, open it the first time as the release notes describe.
Say hiNook lives in your menu bar. Press ⌥⌘W for its window or ⌥⌘Space to ask something from any app.
Connect what you likeChat apps, coding agents, calendars and services, one by one in Settings. The notch is optional: turn it on in Settings › Notch if you like it.

Requirements

What you need.

Mac app
  • macOS 15 (Sequoia) or newer
  • Apple Silicon, M1 or newer
  • Any Mac: the notch is optional, Nook also floats or lives in its window
  • To build: Xcode 26 and XcodeGen
Windows, Linux and Android
  • Rust (stable) and Node.js 22 to build
  • The Tauri prerequisites for your platform
  • For a local brain: Ollama or LM Studio
iPhone Companion
  • Xcode and XcodeGen on a Mac to build it
  • Nook running on a Mac, Windows or Linux computer
  • The same Wi‑Fi network, end‑to‑end encrypted
No API key required. Nook runs on your own computer out of the box. Cloud keys for Claude, OpenAI, Gemini and others are completely optional.
Build from source

Open source, so you can build it yourself.

Nook for Mac, in five commands. Press ⌘R in Xcode to build and run.
$ brew install xcodegen
$ git clone https://github.com/IAMichan/nook.git
$ cd nook/apps/macos
$ xcodegen
$ open Nook.xcodeproj
After every pull, run the update script from the repository root. It pulls the latest changes and regenerates the Xcode projects.
$ ./update.sh
Building the Windows, Linux or Android app (Tauri, in apps/tauri) or the iPhone Companion (apps/ios)? The Quick Start in the README walks through each one, and CONTRIBUTING explains how to send a change.
Running from source? Nook can update itself: when a pull request is merged into main, an Update button appears in the Agents tab. One click fetches main, rebuilds and restarts Nook.

Questions

Before you download.

Is Nook free?

Yes. Nook is open source under the MIT license. With a model on your Mac, questions cost nothing. Only a cloud provider you choose to connect may charge you, on your own account.

Do I need a MacBook with a notch?

No. The notch is an optional extra you can turn on in Settings › Notch. Nook works fully in its own window, from the menu bar and the keyboard, on any Apple Silicon Mac and on an external display.

Which Macs are supported?

Apple Silicon Macs (M1 or newer) with macOS 15 Sequoia or newer. The built‑in local model picks a size that fits your Mac's memory.

Is it safe to open a build that isn't notarized?

The beta is built in the open by a GitHub Actions workflow from the public source, but it is not notarized by Apple yet, so macOS asks you to confirm the first time. The release notes show how. If you'd rather not, build it from source in a few commands.

Which languages does it speak?

The Mac app is in English, Dutch, German, French and Spanish (Settings › General › App language).
