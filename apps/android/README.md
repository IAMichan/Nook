Nog niet geschreven. Deze map is gereserveerd voor de Android-app.

- Voorstel: Kotlin met Jetpack Compose als schil; de gedeelde kern is Swift (`packages/core`), te gebruiken via de Swift-SDK voor Android, of via een aparte protocolkoppeling. Kies dit vóór de eerste regel code.
- Zet hier straks een Gradle-project (`settings.gradle.kts`) en een CI-job met een `paths:`-filter op `apps/android/**`.
